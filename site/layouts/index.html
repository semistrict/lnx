First run

A VM runner that acts like a command.

Build the Rust binary, sign it for Hypervisor.framework, and run a Linux command. The VM owner exits after idle by snapshotting memory and disk state for the next invocation.

Architecture

The initramfs is a handoff, not the root.

The host generates a tiny initramfs, but the real guest stays on the existing systemd ext4 image. That keeps the VM useful for normal Linux workflows while preserving command-shaped ergonomics.
