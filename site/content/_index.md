features:
  - title: "Boots the real root"
    text: "The existing ext4 image stays the systemd root. The initramfs only stages the agent, then hands off to the guest image."
  - title: "Keeps commands warm"
    text: "A detached owner keeps the VM alive briefly, snapshots when idle, and restores the next command from that point."
  - title: "Host ingress built in"
    text: "Local HTTPS hosts terminate on macOS and proxy into guest ports, with generated certificates per .lnx host."
  - title: "Nested restore path"
    text: "Linux-host restore flows can run inside an outer nested-KVM guest while preserving macOS snapshot ergonomics."
flow:
  - "Host writes an initramfs with lnx-agent as /init."
  - "libkrun boots the kernel and attaches rootfs.ext4."
  - "The agent stages itself into the systemd root."
  - "Commands stream over vsock and return the guest status."

  - label: "Build"
